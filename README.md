## Run the Project Locally

Make sure Node.js is installed on your computer.

1. Clone the repository:

   ```bash
   git clone https://github.com/Haseeb-Ahmad-7050/portfolio-ci-cd.git
   ```

2. Open the project folder:

   ```bash
   cd portfolio-ci-cd
   ```

3. Install dependencies:

   ```bash
   npm ci
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Build and Test

Create a production build:

```bash
npm run build
```

Run automated tests:

```bash
npm test
```

Run the project check:

```bash
npm run check
```

## CI/CD Pipeline

GitHub Actions automatically builds and tests the project when changes are pushed to the `main` branch. If the workflow succeeds, the production website is deployed to GitHub Pages.
